# Slice Studio 技术选型与验证报告

## 交付范围

Web 工作台支持本地导入、拖放、自动提取、矩形切片、选区分割、套索、可逆蒙版编辑和项目恢复。透明 PNG 与 ZIP 均以原图像素坐标和裁剪尺寸输出。ZIP 包含可供工程读取的 `manifest.json`。

### 技术架构

| 模块 | 实现与选择依据 |
| --- | --- |
| 工作台 | ES modules、Canvas 2D、CSS 设计变量。图片编辑在独立画布上按设备像素比绘制，缩放平移只改变视图。缩略图按可见范围装载。浏览器保存项目快照、原图和蒙版，支持可携带的 `.slice` 文件。 |
| 颜色分割 | OpenCV 以图像边缘的 Lab 主导颜色估计背景与 JPEG 噪声。较强的颜色差作为连通区域种子，再将邻近弱信号分配到种子。局部前景颜色投影生成软 Alpha。带透明通道的源图直接按 Alpha 连通区域提取，保留原 Alpha。 |
| 选区分割 | 颜色估计适用于留有均匀背景的选区。复杂选区使用 GrabCut 拟合前景和背景，三个迭代步之间支持取消。用户也可指定 MobileSAM。 |
| MobileSAM | ONNX Runtime CPU 运行 TinyViT 编码器、可提示解码器。自动模式在颜色分割无法处理时，复用一次图像嵌入，按网格点取样并筛除低分、低稳定性和重复蒙版。手动模式使用框提示，输出按原图坐标重采样。 |
| 导出与数据 | Pillow 保留裁剪原始尺寸。Python 应用独立蒙版并合成 RGBA。具有背景色的素材默认清理白边，按外轮廓和透明镂空附近的色差估算 RGB 和 Alpha。单素材预览直接显示导出 PNG。服务绑定回环地址并验证本地请求，原图不会发送到外部地址。 |
| 桌面兼容 | 工作台、项目格式和 `/api/v1` 与窗口容器解耦。后续可用 Tauri 2 WebView 加载相同工作台，由宿主管理本地处理进程和文件对话框。桌面封装与原生文件系统适配留在下一阶段。 |

项目中保存的蒙版与原图分离。删除素材、改名、刷改、扩展边界和重新识别支持当前会话撤销。关闭后恢复最近保存的素材状态。PNG 导出的坐标与 EXIF 旋转后的显示方向一致，符合预览与清单使用的坐标系。

## 三张参考图

环境为 Windows 11 x64、Python 3.12、OpenCV 5.0、ONNX Runtime 1.23.2、Chrome 157。灵敏度 50。颜色分割各跑三次，取中位数。MobileSAM 全图每图一次，首张包含模型会话初始化。时间从已解码图像开始，包含候选与蒙版处理。RSS 为执行阶段采样的本进程峰值，包含运行时和当时已保留的图像，非单张蒙版独占内存。

| 样图 | 尺寸 | 颜色候选 | 颜色耗时 | 颜色 RSS 峰值 | MobileSAM 候选 | MobileSAM 耗时 | MobileSAM RSS 峰值 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 1.jpg 复古物件 | 800 × 800 | 14 | 136 ms | 77.0 MiB | 17 | 6.75 s | 453.3 MiB |
| 2.jpg 等距素材 | 600 × 372 | 19 | 32 ms | 67.2 MiB | 14 | 4.83 s | 460.1 MiB |
| 3.jpg 植物水彩 | 1784 × 1681 | 47 | 485 ms | 149.2 MiB | 23 | 4.69 s | 495.8 MiB |

候选数包括粘连和过分割。三张 JPEG 未提供实例或 Alpha 真值，以下为按素材类别复核的实际样例。

- **1.jpg** 的棕色背包与右侧线圈本在颜色分割中粘连。MobileSAM 可独立框出这两件对象，全图取样也会把镜头、袋盖等子区域作为候选，并遗漏细画笔等对象。
- **2.jpg** 的水族箱与旁边的柜台在快速模式下粘连，低桌与小盆栽也受阴影影响。MobileSAM 手动框选成功提取左侧屋形物件。全图网格仍漏掉小坐凳、屏风附近的竖灯和部分花瓶。
- **3.jpg** 的主要花朵和叶片可拆分。颜色模式对接近纸白的浅紫花瓣出现内部空洞，细茎可能漏掉或被分成几段。MobileSAM 全图取样也漏掉多个小花瓣与细叶。
- 颜色模式分别产生 20,027、8,958、114,218 个中间 Alpha 值像素。已验证透明与不透明像素、软边值、原分辨率和默认解码 RGB。反推颜色可减少白底边缘残色，边缘观感仍受背景与前景是否可区分影响。

## 浏览器推理对照

对 `2.jpg` 中同一个屋形物件，使用同一组 MobileSAM ONNX 权重和同一个框提示。Python CPU 设三线程，Chrome 使用跨源隔离页面内的 ONNX Runtime Web WASM 三线程。Python 首次框选 2,253 ms，后两次 1,195 / 1,197 ms。WASM 在会话初始化 771 ms 后，三次为 2,564 / 2,536 / 2,362 ms。两条路径的阈值前景覆盖分别为 3,487 和 3,486 像素，预处理的重采样实现不同。该样本的热推理和运行环境要求支持首版采用本地 Python。WebGPU 未纳入实测。

测试脚本仍可复现这条比较路径。依赖只装入本地测试产物目录。

```powershell
npm install --prefix tests/artifacts/browser-runtime --no-audit --no-fund onnxruntime-web@1.23.2
.venv\Scripts\python.exe -m tests.browser_inference
```

浏览器推理测试生成本地记录 `tests/artifacts/browser-inference.json`。

## 边界

- 重叠遮挡、原图里已与背景混合的像素和贴近背景色的白色细节无法可靠无损还原。工具可以修整蒙版和估算边缘色。
- 全图 MobileSAM 属于点提示候选提取，输出可能包含局部组件或漏掉密集小对象。框提示通常更适合精修单个区域。颜色分割对均匀背景最有效。
- 支持静态 8 位通道或索引色 PNG、JPG、WebP。单图上限为 40 MB、2400 万像素，单项目至多 250 个素材。自动提取有总蒙版面积预算。大文件和低内存设备未接受压力验收。
- 当前实物样图覆盖静物水彩、等距物件及植物素材，像素级精度、真实透明素材集合、复杂 UI 版式和其他浏览器需要独立样本验收。
