# 开发计划与验收
1. 技术验证：真实样本测试自动识别、实例分割、半透明边缘、残色、过度分割、漏检、高清 PNG、浏览器与服务推理、资源占用。记录对比结果与最终选型。
2. Web 工作台：项目架构、设计系统、导入、画布、素材列表、属性面板、项目管理。
3. 核心集成：真实自动识别、分割、精细抠图、蒙版编辑、批量导出，完整闭环。
4. 产品完善：高级编辑、命名、项目保存、性能、异常、自动化测试、浏览器截图验收。
5. 后续桌面：Tauri 封装、原生文件系统、模型管理、GPU 加速、离线能力。当前优先完成前四阶段。
## 验收
真实图片测试，不使用假结果。记录漏检、误检、边缘质量、处理耗时和资源占用；目标由实测基线确定。导出透明通道正确，原始分辨率保留，元数据与素材一致。验证撤销重做、取消任务、错误恢复、项目恢复和不同窗口尺寸。交付启动说明、技术选型、测试结果、已知限制。
现有图片仅覆盖水彩与 UI 设计场景，后续需补充透明素材、纯色素材、像素游戏素材及人工标注真值。当前未实际验证模型。
