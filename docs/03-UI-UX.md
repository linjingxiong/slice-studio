# 商业级 UI/UX
参考 Photoshop、Affinity Photo、Figma、Pixelmator Pro、Blockbench 的专业编辑体验，不直接照搬。Web 也必须是专业桌面工作台。
默认有层次的深色主题；精细设计字体、字重、字号、颜色、间距、图标、边框及交互状态。建立 Design System 和 Design Tokens；图标统一造型、视觉重量及光学对齐，不随意堆砌默认图标库。适配高 DPI 和窗口尺寸。
禁止后台管理式布局、过度圆角、无意义卡片、廉价阴影、大面积渐变、发光、过度留白、Emoji 功能图标。
## 工作台
顶部：导入、项目、智能识别、切图模式、视图、撤销重做、导出。
左侧：选择、框选、分割、套索、画笔、橡皮擦、平移。
中央：原图、识别边界、蒙版、透明预览、前后对比。
右侧：素材缩略图、属性、蒙版参数、尺寸、导出设置。
底部：尺寸、缩放、素材数量、选中状态、任务进度。
## 体验
一键自动提取，尽量减少人工操作。流畅缩放平移、多选、键盘快捷键、右键菜单、画布与列表双向联动。完整空状态、加载、异常、取消、恢复。高级参数按需展开。实际运行并逐项检查界面与交互，不只制作静态 Demo。
